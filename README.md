# 議員総覧

1890年の第1回衆院選から現在まで、衆議院・参議院・貴族院の議員を一人一つの番号でつないだ台帳と、そこから作る名簿のサイトです。全党を対象にします。

## 収めている範囲

- 衆議院：第1回（1890年）から第51回（2026年）までの総選挙51回すべての当選者と、補欠選挙・繰上当選・更正決定による異動
- 参議院：第1回（1947年）から第27回（2025年）までの通常選挙27回すべての当選者と、補欠選挙・繰上当選による異動
- 貴族院：衆院総選挙の各投票日に在職していた議員（1890年の第1回の版は、最初の帝国議会の開会日〈1890年11月29日〉の在職を参考として数える）。在職の種別（皇族・公侯爵・伯子男爵・勅選・多額納税者・帝国学士院会員など）と期間
- 人物：10,172人。生年月日・よみ・出生地・初当選・親族（一部）、各版の時点の党派・会派・役職（閣僚・党首・議長など）

サイトでは、衆院総選挙の投票日ごとに「版」を作り、その日に在職していた衆・参・貴族院の議員を並べます（全51版）。

## ファイル

- 表の項目：`docs/schema.md`
- 作業の記録と検証の結果：`docs/log.md`
- データ：`data/*.csv`（人物 `persons.csv`、在職 `terms.csv`、所属 `affiliations.csv`、役職 `posts.csv`、選挙 `elections.csv`、選挙区 `districts.csv`、政党・会派 `orgs.csv`、親族 `kin.csv`、出典 `sources.csv` など）
- サイト：`index.html`（版の一覧・版・人物を一枚で切り替える）と、台帳から作る `site.json`
- 作り方：`tools/`

## 作り方

```sh
# 参院選の記事から当選者を取り出す
PYTHONPATH=tools python3 tools/run_sanin.py <参院の作業フォルダ>
# 貴族院議員の記事から、各投票日に在職していた議員の名簿を作る
PYTHONPATH=tools python3 tools/run_kizokuin.py <貴族院の作業フォルダ> <参院の作業フォルダ> <日付> [<日付> ...]
# 参院議員の投票日の会派を国会会議録から引く
python3 tools/fetch_kaiha.py data <参院の作業フォルダ>/kaiha.json
# 台帳（data/*.csv）を作る
PYTHONPATH=tools python3 tools/build.py <衆院の作業フォルダ> <参院の作業フォルダ> data
# 会派の行がない貴族院議員の記事を取り直し、院内会派を足す（作業フォルダがなくても台帳だけで動く）
PYTHONPATH=tools python3 tools/kz_kaiha.py data <作業フォルダ>
# 会派の行が一つもない貴族院議員の会派を、帝国議会会議録検索システムの発言者情報から引いて足す（4秒おきに問い合わせるので1時間ほど）
PYTHONPATH=tools python3 tools/kz_kaiha_ndl.py data <作業フォルダ>
# よみ・出生地の空欄を本人の記事から埋める
PYTHONPATH=tools python3 tools/fill_persons.py data <作業フォルダ>
# サイトのデータを作る
python3 tools/build_site.py data site.json
```

作業フォルダ（記事の取得結果などの中間ファイル）はリポジトリに含めていません。

## 残っていること

- 貴族院の院内会派は、本人の記事（本文と情報欄）と、帝国議会会議録検索システムの発言者情報から入れています。1920年の第14回から後の版で在職者の7割台〜9割ほどです。第42回帝国議会（1920年2月）までは各会派が所属議員を公表しておらず（『議会制度百年史 院内会派編』）、それより前の版は記事に伝記として書かれた人だけで、在職者の1割に満たない版から3割ほどまでです（第1回の版は0人）。
- 出生地が分からない人が222人（うち168人は貴族院議員だけの人）、よみが分からない人が8人います（`docs/log.md` の 2026-11-25 の項）。

## おことわり

公開情報（Wikipedia日本語版、公的な選挙記録など）をもとに個人が作成する非公式の資料です。分類には推定が含まれ、それぞれの行に根拠の種類と出典を付けます。
