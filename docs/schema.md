# 表の項目

議員総覧のデータは `data/` の CSV に分けて置く。どの表も人物を `person_id` で指し、氏名や記事名では指さない。
日付は `YYYY-MM-DD`。分からない部分は `YYYY` や `YYYY-MM` まででよい。空欄は「不明」を意味する。

## 番号の付け方

| 種類 | 形 | 例 |
| --- | --- | --- |
| 人物 | `P` + 6桁の連番 | `P000001` |
| 選挙 | 院 + 回次、補選は日付 | `shu-045`、`san-021`、`shu-by-2010-10-24` |
| 在職 | `T` + 6桁の連番 | `T000001` |
| 団体 | `O` + 4桁の連番 | `O0001` |
| 選挙区 | 院 + 制度 + 名前 + 有効期間の始まり | `shu-smd-東京1-1994`、`shu-mmd-北海道1-1992`（中選挙区）、`san-dist-東京`、`san-dist-鳥取・島根`、`san-pr` |
| 出来事 | `E` + 5桁の連番 | `E00001` |
| 出典 | `S` + 6桁の連番 | `S000001` |

一度振った番号は変えず、消さない。在職の番号は「人物・選挙・`route`・その中の何番目か」に結び付けてあり、始まりの日を直しても変わらない。二人を一人と取り違えていたときは新しい番号を振り直す。一人を二人にしていたときは、片方の `note` に `統合→P000123` と書いて残す。

## 根拠の種類（`basis`）

| 値 | 意味 |
| --- | --- |
| `doc` | 当時の資料で確認（公的記録、内閣・総裁選・派閥の記事の表など） |
| `art` | 本人の記事で確認 |
| `est` | 推定。理由を `note` に書く |
| `none` | 未判明 |

## 各表

### persons.csv（人物）
| 列 | 中身 |
| --- | --- |
| person_id | 人物の番号 |
| name | 資料どおりの表記の氏名 |
| name_kana | よみ |
| birth_date / death_date | 生年月日 / 没年月日 |
| birth_pref | 出生地の都道府県 |
| sex | `m` / `f` |
| jawiki_title / jawiki_pageid | Wikipedia日本語版の記事名とページID |
| wikidata_qid | Wikidataの項目ID |
| first_elected / first_house | 国政選挙で初めて当選した年と院（`衆` / `参`）。本人の記事の選挙歴・情報欄の就任日と、台帳の在職のうち早いもの |
| first_basis | 初当選の根拠（`art` 本人の記事、`doc` 台帳の在職）。台帳のいちばん古い回が最初の在職で記事に手がかりがない人は空欄 |
| prev_job | 前職。本人の記事の情報欄「前職」を `／` 区切りで |
| kin_checked | 親族を調べ終えた時点（その日付の資料で確認）。空欄は未調査で、親族の行がないことは「いない」を意味しない |
| note | 統合の記録など |

### aliases.csv（別名）
`kind` は `旧姓`・`通称`・`本名`・`旧字体`・`襲名` のいずれか。`valid_from` / `valid_to` はその名を使った期間。

### elections.csv（選挙）
`house` は `衆` / `参`。`kind` は `総選挙`・`通常選挙`・`補欠選挙`・`再選挙`。`system` は `小選挙区制`（1890〜1898、1920〜1924）・`大選挙区制`（1902〜1917、1946）・`中選挙区制`・`並立制`・`地方区全国区`・`選挙区比例区` など。`seats` は定数。

### terms.csv（在職）
一人が議席を得た一回分。貴族院は選挙を持たないので `election_id` は空にし、`peer_type` に `皇族`・`公爵`・`侯爵`・`伯爵互選`・`子爵互選`・`男爵互選`・`勅選`・`学士院`・`多額納税` などを書く。
`route` は `小選挙区`・`比例復活`・`比例単独`・`選挙区`・`比例`・`比例（特定枠）`・`合併選挙`・`地方区`・`全国区`・`中選挙区`・`大選挙区`・`補選`・`再選挙`・`繰上` のいずれか。`list_rank` は比例名簿の順位。`end_reason` は `任期満了`・`解散`・`辞職`・`死去`・`退職`（立候補による自動失職を含む）・`失職`・`当選無効`・`除名`・`転出` など。`note` は扱いの注記（補選のないまま残った欠員、記事の誤りを直した箇所など）。

- 参院の `election_id` は、その議席を得た通常選挙の回。補選・再選挙・繰上で入った人も、前任者の組の回（`san-025` など）にする。合併選挙（任期3年）の当選者だけは、選ばれた通常選挙の回になる。
- 通常選挙の当選者の `start_date` は任期の始まり（前の同じ組の任期満了の翌日、投票日がそれより後なら投票日）。補選・再選挙は投票日。法律上は当選の告示の日から在職するので、数日ずれる。
- 繰上当選の `start_date` は繰上当選の日。衆院の選挙記事に月までしか書かれていない回は `YYYY-MM`。

### affiliations.csv（所属）
政党・会派・派閥・グループへの所属の期間。`role` は会長・幹事長などの団体内の役職。
期間が分からず「その日に所属していた」ことだけが分かっているときは、`start_date` / `end_date` を空にして `as_of` にその日を書く（自民党版から取り込んだ派閥など）。
参院議員の各版の投票日の党派も `as_of` の行で持つ（`note` の先頭が `投票日の党派；`、出典は国会会議録）。その日に無所属だった人は `org_id` を空にした行で表す。注記には、投票日にいちばん近い発言の会派とその日付、当選時の党派から移したときの理由を書く。派閥の行の `note` の先頭の【】は、その時点の呼び名（「清和会（町村派）」「旧安倍派（清和会）」など）。

### orgs.csv（団体）
`kind` は `政党`・`会派`・`派閥`・`グループ`。派閥の `lineage` は派閥の系譜（`清和会系`・`平成研系`・`宏池会系`・`志帥会系`・`為公会系`・`近未来系`・`番町研系`・`無派閥グループ`・`無派閥`）。派閥の行は会長の名前で呼び名が変わっても同じ団体を一行にし（清和政策研究会、平成研究会など）、その時点の呼び名は所属の行の注記【】に書く。政党の `lineage` は系譜（`政友会系`・`民政党系`・`保守系`・`社会党系`・`非自民再編系` など、計画書の系譜の章による）。`predecessors` / `successors` は前身・後身の `org_id` をセミコロン区切りで。

### posts.csv（役職）
閣僚、副大臣、政務官、党の執行部、議長・委員長など。`kind` は `閣僚`（内閣官房副長官・首相補佐官を含む）・`副大臣`・`大臣政務官`・`党首`・`党執行部`・`党の幹部`・`衆議院の役職`・`参議院の役職`。`body` は内閣名や党名（「麻生内閣」「自由民主党（高市総裁）」など）。就任日・退任日が分からず「その日に就いていた」ことだけ分かっているときは `as_of` に日付を書く。同じ時点の行は、資料の並び（内閣の序列など）のまま。

### kin.csv（親族）
`other_person_id` が台帳にいる相手、いなければ `other_name` と `other_title`（肩書）。`category` は `血族`・`姻族`・`配偶者`、`line` は `直系`・`傍系`、`degree` は親等。続柄は本人から見たもの（`relation=父` なら相手は本人の父）。`national` は相手が国会議員（経験者を含む）なら `1`。`other_person_id` は、相手が国会議員で台帳に同じ名前の人が一人だけいるときに付ける。

### districts.csv（選挙区）
区割りの一つの版。同じ名前でも区割りが変われば別の行にする。中選挙区（`shu-mmd-…`）の `seats` はその選挙での定数（当選者の数）、`valid_from` はその区割りが最初に使われた選挙の前の改正の年（第40回は1992年の改正）。参院の選挙区は都道府県ごとに一行（合区の鳥取・島根、徳島・高知は2016年からの別の行）、比例区は一行で、定数の変遷はまだ入れていない。

### events.csv / event_people.csv（出来事）
`kind` は `暗殺・テロ`・`除名・懲罰`・`議事の乱闘`・`汚職・疑獄`・`分裂・造反`・`言論と弾圧`・`記録` など。刑事事件は `stage`（`逮捕`・`起訴`・`判決`・`確定`）と `outcome`（`有罪`・`無罪`・`不起訴`・`公訴棄却`）を分けて書く。関わった議員は `event_people.csv` に一人一行で、`role` を付ける。

### sources.csv（出典）
`kind` は `公的記録`・`刊行資料`・`wikipedia`・`報道`。Wikipediaは `revision_id` に取得した版のIDを書く。
