# 表の項目

議員総覧のデータは `data/` の CSV に分けて置く。どの表も人物を `person_id` で指し、氏名や記事名では指さない。
日付は `YYYY-MM-DD`。分からない部分は `YYYY` や `YYYY-MM` まででよい。空欄は「不明」を意味する。

## 番号の付け方

| 種類 | 形 | 例 |
| --- | --- | --- |
| 人物 | `P` + 6桁の連番 | `P000001` |
| 選挙 | 院 + 回次、補選は日付 | `shu-045`、`san-021`、`shu-by-2010-10-24` |
| 在職 | `T` + 6桁の連番 | `T000001` |
| 団体 | `O` + 4桁の連番 | `O0001` |
| 選挙区 | 院 + 制度 + 名前 + 有効期間の始まり | `shu-smd-東京1-1996` |
| 出来事 | `E` + 5桁の連番 | `E00001` |
| 出典 | `S` + 6桁の連番 | `S000001` |

一度振った番号は変えず、消さない。二人を一人と取り違えていたときは新しい番号を振り直す。一人を二人にしていたときは、片方の `note` に `統合→P000123` と書いて残す。

## 根拠の種類（`basis`）

| 値 | 意味 |
| --- | --- |
| `doc` | 当時の資料で確認（公的記録、内閣・総裁選・派閥の記事の表など） |
| `art` | 本人の記事で確認 |
| `est` | 推定。理由を `note` に書く |
| `none` | 未判明 |

## 各表

### persons.csv（人物）
| 列 | 中身 |
| --- | --- |
| person_id | 人物の番号 |
| name | 資料どおりの表記の氏名 |
| name_kana | よみ |
| birth_date / death_date | 生年月日 / 没年月日 |
| birth_pref | 出生地の都道府県 |
| sex | `m` / `f` |
| jawiki_title / jawiki_pageid | Wikipedia日本語版の記事名とページID |
| wikidata_qid | Wikidataの項目ID |
| note | 統合の記録など |

### aliases.csv（別名）
`kind` は `旧姓`・`通称`・`本名`・`旧字体`・`襲名` のいずれか。`valid_from` / `valid_to` はその名を使った期間。

### elections.csv（選挙）
`house` は `衆` / `参`。`kind` は `総選挙`・`通常選挙`・`補欠選挙`・`再選挙`。`system` は `小選挙区制`（1890〜1898、1920〜1924）・`大選挙区制`（1902〜1917、1946）・`中選挙区制`・`並立制`・`地方区全国区`・`選挙区比例区` など。`seats` は定数。

### terms.csv（在職）
一人が議席を得た一回分。貴族院は選挙を持たないので `election_id` は空にし、`peer_type` に `皇族`・`公爵`・`侯爵`・`伯爵互選`・`子爵互選`・`男爵互選`・`勅選`・`学士院`・`多額納税` などを書く。
`route` は `小選挙区`・`比例復活`・`比例単独`・`選挙区`・`比例区`・`地方区`・`全国区`・`中選挙区`・`大選挙区`・`補選`・`繰上` のいずれか。`list_rank` は比例名簿の順位。`end_reason` は `任期満了`・`解散`・`辞職`・`死去`・`失職`・`除名`・`転出` など。

### affiliations.csv（所属）
政党・会派・派閥・グループへの所属の期間。`role` は会長・幹事長などの団体内の役職。

### orgs.csv（団体）
`kind` は `政党`・`会派`・`派閥`・`グループ`。`lineage` は系譜（`政友会系`・`民政党系`・`保守系`・`社会党系`・`非自民再編系` など、計画書の系譜の章による）。`predecessors` / `successors` は前身・後身の `org_id` をセミコロン区切りで。

### posts.csv（役職）
閣僚、副大臣、政務官、党の執行部、議長・委員長など。`body` は内閣名や党名。

### kin.csv（親族）
`other_person_id` が台帳にいる相手、いなければ `other_name` と `other_title`（肩書）。`category` は `血族`・`姻族`・`配偶者`、`line` は `直系`・`傍系`、`degree` は親等。続柄は本人から見たもの（`relation=父` なら相手は本人の父）。

### districts.csv（選挙区）
区割りの一つの版。同じ名前でも区割りが変われば別の行にする。

### events.csv / event_people.csv（出来事）
`kind` は `暗殺・テロ`・`除名・懲罰`・`議事の乱闘`・`汚職・疑獄`・`分裂・造反`・`言論と弾圧`・`記録` など。刑事事件は `stage`（`逮捕`・`起訴`・`判決`・`確定`）と `outcome`（`有罪`・`無罪`・`不起訴`・`公訴棄却`）を分けて書く。関わった議員は `event_people.csv` に一人一行で、`role` を付ける。

### sources.csv（出典）
`kind` は `公的記録`・`刊行資料`・`wikipedia`・`報道`。Wikipediaは `revision_id` に取得した版のIDを書く。
